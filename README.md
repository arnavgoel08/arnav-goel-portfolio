# Arnav Goel — Portfolio

**Live website:** https://arnav-goel-portfolio.vercel.app

Personal portfolio built with HTML, CSS and JavaScript, with AI assistance.

## Features
- Scroll-driven project panels and certificate gallery
- Cursor spotlight, particles, magnetic buttons and hover effects
- Interactive toolkit, education timeline and social links
- Responsive layouts and reduced-motion support

## Run locally
```bash
python -m http.server 8000
```
Open http://localhost:8000. No dependencies or build step required.

## Edit
Edit `index.html`. Images and certificates are alongside it in the repository root. Keep relative file names unchanged when replacing an asset.

## Deploy on Vercel
Use framework **Other**, no build command, and the repository root as the output. Connect this repository in the existing Vercel project's Git settings for automatic deployment on pushes to `main`.

Personal photos and credentials belong to their respective owners. Certificates document participation or completion as stated by each issuer.
